## Delivery Report CSV (Max) page (the Maxpro page)
Top: search "Find order / customer", page numbers and ALL, a download icon.
Buttons: White Glove Orders, Send Bulk Email, Export Order Wise, Export Product Wise.
Columns: tick box, S.No., Date, Order No., Address 1, Address 2, Capacity, Volume, Distribution Centre (CFS), Drop Window Start (7:30), Drop Window End (16:00), Drop Duration (15), Client Name, Contact No., Date From, Date To, Order Status (coloured label), Brands.
Rows seen are orders in statuses such as Allocated From Stock, Exchange/Display Stock and Coming IN. New: brand / vendor filter.
